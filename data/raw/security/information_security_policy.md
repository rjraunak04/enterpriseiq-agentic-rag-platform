# Information Security Policy

## 1. Purpose

This policy establishes baseline information-security requirements for NexaCorp Technologies.

## 2. Authentication

Multi-factor authentication is required for remote access and for systems classified as business critical.

## 3. Security Incident Reporting

Suspected phishing, credential compromise, malware, or unauthorized access must be reported to the Security Operations team immediately through the approved security-incident channel.

## 4. Company Devices

Restricted information should be accessed only from approved company-managed devices unless Information Security has authorized an exception.

## 5. Data Handling

Employees must handle information according to Data Classification Policy SEC-002.

## 6. Credential Protection

Passwords, authentication tokens, recovery codes, and private keys must not be shared with another person.
